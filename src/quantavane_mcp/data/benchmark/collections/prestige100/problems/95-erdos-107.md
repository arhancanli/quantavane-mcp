# 95. A counterexample to the Erdős-Szekeres conjecture (Erdős problem #107)

Family: Erdős problems. Benchmark problem: `erdos-107`.

**Best known:** no counterexample known, none. Also known: the conjecture is proved for n ≤ 6 (f(6) = 17, G. Szekeres and L. Peters, 2006).

**To beat it:** 2^(n-2) + 1 points in general position with no convex n-gon, for some n (at least 33 points with no convex heptagon).

**Keeper:** [Erdős Problems (T. F. Bloom)](https://www.erdosproblems.com), read 2026-11-09 15:58 +04 (problem pages and the database teorth/erdosproblems (data/problems.yaml)).

## The problem

Find points in the plane, no three on a line, with at least 2^(c-1) + 1 points but no c + 1 of them in convex position, for some c: a counterexample to the Erdos-Szekeres ('happy ending') conjecture that any 2^(n-2) + 1 points in general position contain a convex n-gon. The conjecture holds for n <= 6, so a counterexample has at least 33 points. A valid counterexample scores 1 (Erdos offered $500 for the problem).

## Why it matters

The 'happy ending' problem is one of Erdős's best-known conjectures, with a $500 prize (erdosproblems.com/107): every 2^(n-2) + 1 points in general position contain a convex n-gon. It is proved for n ≤ 6, and a single point set without a convex heptagon on 33 points would disprove it.

Sources: [T. F. Bloom, Erdős Problem #107](https://www.erdosproblems.com/107).
