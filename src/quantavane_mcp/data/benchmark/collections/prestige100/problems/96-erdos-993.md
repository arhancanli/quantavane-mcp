## The problem

Find a tree or forest whose independent set sequence i_0, i_1, ... (i_k = the number of independent sets of k vertices) is not unimodal: it falls and later rises again. Alavi, Malde, Schwenk and Erdos (1987) asked whether this can happen. A valid counterexample scores 1.

## Why it matters

Alavi, Malde, Schwenk and Erdős showed in 1987 that independent set sequences of general graphs can follow any pattern, and asked whether those of trees are always unimodal (erdosproblems.com/993). The database marks it falsifiable: one tree settles it.

Sources: [T. F. Bloom, Erdős Problem #993](https://www.erdosproblems.com/993).
